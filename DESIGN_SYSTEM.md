# Design System

## Typography
- Serif headings: Cormorant Garamond
- Interface text: DM Sans

## Components
- Header
- Search panel
- Category card
- Listing card
- Dashboard metric card
- Requirement form
- Status feedback

## Interaction rules
- Native form validation precedes API submission.
- API errors are displayed without fabricated success.
- Every navigation target must resolve to an implemented route.
