# Product Requirements

## Vision
Create an independent India-wide wedding marketplace where customers discover vendors, submit requirements, compare quotations, purchase products and book services.

## Brand
Use the configurable placeholder brand "Wedlock". The final logo, domain and identity are not supplied.

## Roles
Guest, customer, vendor owner, vendor staff, wedding planner, support, verification, finance, content manager and super admin. Each identity may hold multiple permitted roles.

## MVP capabilities
1. Responsive public discovery and search.
2. Category and listing browsing.
3. Multi-category requirement submission.
4. Automatic lead creation for eligible listings.
5. Quotations and quotation status.
6. Multi-seller cart and seller-order API data model.
7. Service booking with duplicate-date holds.
8. Customer, vendor and admin dashboard routes.
9. Admin marketplace summary.

## Acceptance scenarios
- A customer can submit a valid requirement.
- The API rejects invalid requirement fields.
- Matched leads are created for eligible listings.
- A duplicate listing/date booking is rejected.
- Critical API workflows have automated tests.
