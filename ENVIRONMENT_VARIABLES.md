# Environment Variables

Frontend:
- `API_URL`: server-side FastAPI base URL
- `NEXT_PUBLIC_API_URL`: browser-side FastAPI base URL

Backend:
- `MONGODB_URI`: MongoDB connection string
- `MONGODB_DATABASE`: database name
- `REDIS_URL`: Redis URL
- `JWT_SECRET`: signing secret for production authentication
- `PAYMENT_PROVIDER`: configured provider name
- `PAYMENT_API_KEY`: provider key
- `PAYMENT_API_SECRET`: provider secret
- `PAYMENT_WEBHOOK_SECRET`: signed webhook secret
