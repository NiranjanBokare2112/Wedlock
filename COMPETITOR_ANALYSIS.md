# Competitor Analysis

No external browsing was performed during implementation, so no platform-specific observation is claimed.

## Feature comparison target
| Capability | IndiaMART-style reference target | Wedlock proposal |
|---|---|---|
| Search | Supplier discovery and filters | Category, city and keyword search |
| Requirement | One requirement sent to suppliers | Multi-category wedding requirement with lead matches |
| Quotation | Supplier proposals | Structured quotation, revision and acceptance state |
| Vendor profile | Business details and portfolio | Verification, portfolio, packages and availability |
| Ecommerce | Product sourcing | Multi-vendor cart and seller orders |
| Booking | Not always marketplace-native | Availability holds, advance payments and confirmations |
| Admin | Internal moderation | Verification, listing, lead, refund and audit controls |
